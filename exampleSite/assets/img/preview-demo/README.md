# Local preview example posters

These screenshots come from the public local pages at `/preview-demo/ready/`,
`/preview-demo/activity/` and `/preview-demo/silent/`. The workspace is interactive;
the Silent page deliberately never announces readiness.

Each page has light and dark captures at the advertised native reference sizes:
desktop1440×900, tablet820×1180 and mobile402×874, with device scale factor1.
Chrome156.0.8078.47 captured ordinary local HTTP pages with no external requests.
The legacy frame retains its border; window mode exposes the full native viewport.

`manifest.json` records the exact HTML, JavaScript, CSS and screenshot SHA256 values.
The shared placeholder and earlier generic poster assets remain unchanged.
